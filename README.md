# Uptime Check

Проверяет доступность нескольких сайтов, HTTP-статус и время ответа. Удобно для быстрой диагностики своих сервисов.

```bash
python3 uptime_check.py ezhik.click bio.ezhik.click
python3 uptime_check.py https://example.com --json
```

Поддерживает читаемый и JSON-вывод, таймаут и корректный код завершения для автоматизации.
